# AgeVerificationBypass

A BetterDiscord plugin that attempts to bypass Discord's age verification prompt, allowing you to access NSFW channels without completing Discord's age verification process.

Installation

Install BetterDiscord
.

Download the plugin file.

Open Discord and go to:
Settings → BetterDiscord → Plugins

Click Open Plugins Folder.

Move the downloaded .plugin.js file into the folder.

Return to Discord's Plugins settings.

Enable Discord Age Verification Bypass.

Disclaimer

This plugin is unofficial and may stop working if Discord changes its age-verification system. Use it at your own risk!
